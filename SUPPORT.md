# Getting help

- **Usage**: start with the [README](README.md) and `wspace --help` /
  `wspace <command> --help`. `wspace doctor` checks git and your setup.
- **Bugs**: open a [bug report](https://github.com/kivoradigital/wspace/issues/new/choose)
  with the exact commands and the output of `wspace version`.
- **Ideas**: open a [feature request](https://github.com/kivoradigital/wspace/issues/new/choose)
  describing the problem you want to solve.
- **Security issues**: never in public. Follow [SECURITY.md](SECURITY.md).

wspace is maintained by Kivora Digital S.L. on a best-effort basis; there is
no guaranteed response time for issues or pull requests.
